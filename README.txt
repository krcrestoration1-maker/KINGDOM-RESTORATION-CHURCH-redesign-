RESTORATION EMBASSY / KINGDOM RESTORATION CHURCH WEBSITE REDESIGN
================================================================

This is a responsive static website starter designed for Kingdom Restoration Church — Restoration Embassy Kisumu.

WHAT IS INCLUDED
- index.html: full one-page website
- styles.css: responsive layout and visual design
- script.js: mobile navigation and current copyright year

IMPORTANT BEFORE PUBLISHING
1. This is a NEW project starter, not the original source code for restorationembassy.vercel.app.
2. The photographs currently use remote Unsplash image URLs. Replace them with church-approved photographs when available.
3. The KRC mark is styled text, not the official church logo. Replace it with the official logo file before launch.
4. Verify the service time, contact details, venue and all ministry names before publishing.
5. Sermon videos and event dates are intentionally not fabricated. Add official links and confirmed event details.
6. M-Pesa giving instructions are not displayed because verified paybill/till/account details were not supplied.
7. Test every page section and link on a phone and desktop before sharing the site publicly.

DEPLOY USING VERCEL DROP
1. Open https://vercel.com/drop and sign in to your Vercel account.
2. Upload this ZIP file. If asked, choose the extracted project folder or upload the ZIP as supported by the current page.
3. Give the new project a name such as restoration-embassy-redesign-preview.
4. Deploy it and open the preview URL to review.
5. This creates a SEPARATE project and URL. It does not automatically replace the current website.
6. Keep the existing site live until the new design is approved and you decide how to connect a domain.
